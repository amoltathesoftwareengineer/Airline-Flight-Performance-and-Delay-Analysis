# ✈️ Airline Flight Performance and Delay Analysis

## 📌 Project Overview

The **Airline Flight Performance and Delay Analysis** project focuses on analyzing airline operational data to understand flight delays, cancellations, and on-time performance. Using SQL and Power BI, this project aims to identify performance trends, analyze delay patterns, and generate meaningful insights to support data-driven decision-making.

## 🎯 Project Objectives

- Analyze flight arrival and departure delays.
- Evaluate airline-wise on-time performance.
- Identify airport-wise flight delay patterns.
- Analyze flight cancellations and delay trends.
- Track key performance indicators (KPIs).
- Create interactive dashboards for data visualization.

## 🛠️ Technologies Used

- **SQL / MySQL** – Data querying and analysis
- **Microsoft Excel** – Data cleaning and preparation
- **Microsoft Power BI** – Interactive dashboards and visualization

## 📊 Key Performance Indicators (KPIs)

- Total Number of Flights
- Average Arrival Delay
- Average Departure Delay
- On-Time Performance Rate
- Flight Cancellation Rate
- Airline-wise Flight Performance
- Airport-wise Delay Analysis
- Monthly Flight Delay Trends

## 🔍 Project Features

- Data cleaning and preparation
- SQL-based data analysis
- Airline performance comparison
- Flight delay and cancellation analysis
- Monthly and airport-wise trend identification
- Interactive Power BI dashboard development
- KPI reporting and business insights
